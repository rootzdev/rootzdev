## 👋 About me

I'm a developer from Türkiye 🇹🇷 who likes taking things apart to see how they work, then building my own version.

- 🌐 **Web:** website themes and design on the front, backend on the server side
- 🎮 **Games:** FiveM scripts in Lua, Minecraft plugins and clients in Java
- 🖥️ **Windows:** small tools and utilities in C and C#
- 🌱 Learning **game development** basics with Unity and Unreal Engine, plus low-level programming and reverse engineering
- 💬 Find me on Discord as **rootzdev**
